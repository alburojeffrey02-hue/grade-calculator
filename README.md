# Grade Calculator

Name: Jeffrey C. Alburo
Section: IT3R4

Description
A command-line program that takes a list of scores, computes the
average, and shows the letter grade.

How to Run
1. Install Python 3.
2. Clone the repo: "git clone https://github.com/alburojeffrey02-hue/grade-calculator.git"
3. Go into the folder: "cd grade-calculator"
4. Run: "python grade_calculator.py"
5. Type each score and press Enter. Type "done" to see the result.
